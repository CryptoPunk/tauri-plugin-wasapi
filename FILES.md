# FILES.md

Project structure for `tauri-plugin-wasapi`.

## Rust Source (`src/`)

| File          | Description                                                         |
|---------------|---------------------------------------------------------------------|
| `lib.rs`      | Plugin entrypoint — registers commands and manages plugin state     |
| `commands.rs` | Tauri command handlers (list_devices, list_processes, start/stop)   |
| `desktop.rs`  | Desktop implementation — WASAPI capture logic and session manager   |
| `mobile.rs`   | Mobile stub — all methods return `Error::Unsupported`               |
| `models.rs`   | Shared data models (AudioDevice, StreamEvent, etc.)                 |
| `error.rs`    | Error types                                                         |

## Documentation (`doc/`)

| File              | Description                                                     |
|-------------------|-----------------------------------------------------------------|
| `architecture.md` | Deep-dive into technical architecture and threading models      |
| `api_reference.md`| Detailed reference for all exported functions and types         |
| `troubleshooting.md` | Common issues (COM errors, privacy settings, OS limitations) |
| `permissions.md`  | Detailed guide to configuring Tauri 2 permissions for the plugin |

## Frontend (`guest-js/`)

| File       | Description                                                    |
|------------|----------------------------------------------------------------|
| `index.ts` | TypeScript API — listDevices, listProcesses, startCapture, etc |

## Permissions (`permissions/`)

| File                          | Description                                         |
|-------------------------------|-----------------------------------------------------|
| `default.toml`                | Default plugin permissions (denies all by default)  |
| `schemas/schema.json`         | JSON schema for plugin permissions                  |
| `autogenerated/reference.md`  | Human-readable documentation for valid permissions  |

## Examples (`examples/`)

| Directory   | Description                                                     |
|-------------|-----------------------------------------------------------------|
| `tauri-app` | A complete Tauri application demonstrating the WASAPI plugin    |

## Root Configuration

| File             | Description                                     |
|------------------|-------------------------------------------------|
| `Cargo.toml`     | Rust crate configuration and dependencies       |
| `package.json`   | NPM package configuration and dependencies      |
| `tsconfig.json`  | TypeScript compiler configuration               |
| `vite.config.ts` | Vite configuration for bundling `guest-js`      |
| `build.rs`       | Tauri plugin build script                       |
| `README.md`      | Main project documentation                      |
| `FILES.md`       | This file — project structure overview          |
